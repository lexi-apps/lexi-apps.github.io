Guide / WOLF RPG Editor / Step by step

How to translate a WOLF RPG Editor game, step by step.

WOLF RPG Editor (WOLF RPGエディター) is behind many Japanese indie RPGs and horror games. This guide explains where a WOLF RPG game keeps its text, what can go wrong when you translate it, and how to translate it into your language for free with Lexi Game Translator — inside the Data folder or the Data.wolf archive, without breaking control codes or file names.

Why translating a WOLF RPG game is tricky

WOLF RPG games have no translation folder. Dialogue, choices, item and skill names and menu words live inside binary data files, which released games often pack into one archive:

Loose Data folder

Data/MapData/*.mps (maps and their events), Data/BasicData/CommonEvent.dat (common events) and the database files such as DataBase.dat, CDataBase.dat and SysDatabase.dat.

Packed .wolf archives

The same files packed into Data.wolf (or other .wolf files) — a DXArchive that ordinary editors cannot open. Some archives use the standard key, others a custom password.

On top of that, message lines contain control codes:

\c[2]Mina\c[0]: You have \self[3] potions left.

Codes like \c[2], \self[3], \cdb[…] or \font[…] insert colours, values and font changes. If a translator drops a backslash or a bracket, the line shows garbage. And not every string in the data is meant to be read by the player: picture and sound file names, numbers and internal IDs look like text but are used by the game's logic — change them and the game can no longer find its files.

Lexi Game Translator reads WOLF's binary formats with a strict parser. It collects only player-facing text, leaves file names, numbers and IDs alone, and does not write a translated line in which a control code went missing. If a file's structure is not exactly what it expects, Lexi skips that file instead of guessing.

Before you start

  • A PC with Windows 10 or 11 (64-bit). The installer does not need administrator rights.
  • The game extracted on your PC — the folder that contains Game.exe and either a Data folder or a Data.wolf file. You can also drag and drop the folder straight onto the Lexi window.
  • Some free disk space: before writing, Lexi copies every file and archive entry it is about to change into a backup folder inside the game folder.
  • An internet connection for the online translation engines — or a local AI model with Ollama, LM Studio, or llama.cpp for fully offline translation in Lexi Pro.

Translate a WOLF RPG game with Lexi Game Translator

  1. Download and install the app

    Lexi Game Translator is a free app for Windows 10 and 11 (64-bit). Download the installer from the official GitHub Releases page and run it. If Windows SmartScreen shows a blue warning the first time, the install help page shows what to click.

  2. Pick or drop the game folder

    Select the game folder (or drop it onto the window). Lexi recognizes WOLF RPG Editor from a .wolf archive or from the BasicData and MapData folders, and runs a read-only scan: it counts the lines and shows which files they come from without changing anything. .wolf archives with the standard key are read directly — no separate unpacking tool is needed.

    What gets collected: messages and choices from map events and common events, text set by string operations and passed to event calls (only when it looks like real words), and text fields of the databases — such as names and descriptions. Lexi also reads the game title from Game.dat to show it in the app.

  3. Choose your target language and translation engine

    Pick your target language from 30+ supported languages and an engine:

    1. Free keyless (Basic)

    Google + Microsoft Edge run in parallel with automatic fallback. No account, no API key, unlimited lines.

    2. Own key machine (Basic)

    Bing / Microsoft Translator and Yandex Translate are also unlocked in Basic when you enter your own API key.

    3. Cloud & local AI (Lexi Pro)

    1-click presets for cloud AI with your own key, or offline Ollama / LM Studio / llama.cpp. Patreon $6/mo + 3-day free AI trial.

    Whenever a cloud AI job could incur API costs, Lexi calculates the estimated amount up front, waits for your explicit approval, and enforces any spending cap you set.

  4. Press Translate

    Press Translate and watch the lines appear live. Before anything is written, Lexi copies each loose file it will change — and the original of each archive entry it will change — into a backup folder inside the game folder, and automatically locks your first backup. You can pause or stop at any time; finished lines are kept and the next run continues from there.

    The translation is then written in place: into the .mps and .dat files of a loose Data folder, or back into the .wolf archive. Only the text records change; map tiles, movement routes, numbers and everything Lexi does not recognise stay byte for byte as they were. Every line is checked first — if a control code is missing from the translation, that line is not written.

  5. Launch the game and check

    Press Launch game, play the first scenes and open the menu. WOLF RPG has no separate translation layer, so there is no in-game language switch: the game simply starts in your language. To go back to the original, restore the first backup in Backups and memory.

Letters, encodings and Smart Deaccent

Games made with WOLF RPG Editor 2 store their text in Shift-JIS, a Japanese code page. It has no room for many accented letters — Turkish ğ and ş, for example. Games made with WOLF RPG Editor 3 use UTF-8, which can store every letter.

Lexi checks which one your game uses. If it is Shift-JIS and your language needs letters it cannot store, the Autopilot card lists those letters and — for languages written with accented Latin letters — suggests Smart Deaccent, which writes them without their accents while leaving codes untouched. If a translated line still contains such a letter, Lexi saves that file in the UTF-8 format of WOLF RPG Editor 3. Launch the game and check that the letters really show up; if they do not, turn on Smart Deaccent and translate again.

Practical tips for a cleaner translation

Protected archives
.wolf archives with a custom password cannot be opened, and files protected by WOLF RPG Editor Pro are skipped. Lexi never tries to break such protection.
What stays untranslated
Words drawn into pictures (title screens, signs) are image pixels, not text data, so they are not part of the scan. File names, numbers and internal IDs are left alone on purpose, and a file whose structure Lexi cannot read with certainty is skipped instead of guessed.
Glossary
Use the Glossary to fix character names, places, spells and items, so they read the same in dialogue and in the database.
Quality & CSV
The Quality and editing page finds empty, untranslated or broken lines. Retranslate problems sends only those lines again, and you can fix any line in the built-in editor or export/import CSV to review it in Excel or LibreOffice.
Game updates
An update usually replaces Data.wolf or the data files with new originals. Scan and translate again: finished lines come back from the translation memory, and only new or changed lines go to the engine.

Personal use and sharing

A translation made this way is for your own use. The game's story, text and art belong to its developer, so before you share a translated patch publicly (for example with Lexi's patch .zip export), ask the developer for permission.

FAQ / WOLF RPG translation

Short answers.

Is Lexi Game Translator free?

Yes. The Basic tier is free, needs no account or sign-in, and translates with the keyless built-in Google and Microsoft Edge chain (plus Bing and Yandex if you provide your own API key). AI translation is optional and unlocked with Lexi Pro ($6/month on Patreon), with a one-time 3-day free AI trial per computer.

Which WOLF RPG Editor games work?

Games made with WOLF RPG Editor 2 (Shift-JIS text) and WOLF RPG Editor 3 (UTF-8 text). Lexi reads a loose Data folder (MapData .mps maps, CommonEvent.dat and the database .dat files) and .wolf archives that use the standard key. Archives with a custom password and files protected by WOLF RPG Editor Pro are skipped.

Does Lexi change my game files?

Yes. WOLF RPG has no separate translation folder, so the translation is written into the game's own data files or back into its .wolf archive. Before writing, Lexi copies every file and every archive entry it changes into a backup folder inside the game folder, and the first backup is locked automatically. Restore in Backups and memory brings the original back.

Can I switch back to the original language?

WOLF RPG translations have no in-game language switch. To go back, restore the original backup in Backups and memory. Finished lines stay in Lexi's translation memory, so you do not have to translate them again later.

Letters are missing or look wrong. What can I do?

Games made with WOLF RPG Editor 2 store text in Shift-JIS, a Japanese code page without letters such as ğ or ş. Lexi checks this. If your language needs letters the game cannot store and uses accented Latin letters, Autopilot lists them and suggests Smart Deaccent, which writes those letters without their accents.

Why are some texts still in the original language?

Text drawn into pictures is not part of the text scan, file names, numbers and IDs are left alone on purpose, and a file whose structure Lexi cannot read with certainty is skipped instead of guessed. Text from string operations and event calls is only taken when it looks like real words, so the game's code keeps working.

Can I share my translation with others?

Lexi can export a translation patch as a .zip file, but the game's text belongs to its developer. Translate for your own use, and ask the developer for permission before you share a translated patch publicly.
