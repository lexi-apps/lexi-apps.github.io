01 / Lexi Ren'Py Translator / Windows

Point. Choose. Translate.

Lexi Ren'Py Translator takes a Ren'Py visual novel and writes it out in another language. The whole job is three steps.

How it works

  1. 01

    Pick the game folder

    Point the app at the folder of your Ren'Py game.

  2. 02

    Choose a language and an engine

    Pick the language you want and how to get there: the free machine translation engines in Basic, or AI translation with your own API key in Plus.

  3. 03

    Translate

    A backup is made first. Then the translations are written to the game's tl/ folder. If the run stops, it can be resumed where it left off.

The app, screen by screen

What is inside

Engines
Free machine translation engines in Basic: Google, Edge, Bing, Yandex, and an automatic free chain. Plus adds AI translation with your own API key.
Memory
Translation memory: lines that are already translated are reused.
Resume
A run that stops can be resumed where it left off.
Backups
A backup is made before anything is written.
Names
Character names are kept as they are, not translated like ordinary words.
Fonts
For Chinese, Japanese, Korean, Thai and Hindi, a suitable font is added to the game automatically.
Menus
Ren'Py's own menu texts (Save, Load, Preferences) come pre-translated in 21 languages.
Game updates
When a game gets a new version, your previous translation loads back; only new and changed lines are translated.
Glossary
A glossary of terms.
Editor
A translation editor and quality checks.
Preview
Live preview.
In-game
An optional in-game language switcher.
Direction
Right-to-left languages are supported.
Interface
In 11 languages: English, Turkish, Russian, Chinese, Japanese, Spanish, Brazilian Portuguese, German, French, Korean and Polish.
Themes
12 color themes.
Updates
Automatic updates.
Support
A built-in “Report a problem”.

FAQ / Lexi Apps

Short answers.

Is it really free?

Lexi Ren'Py Translator Basic is free and comes with the machine translation engines. Lexi Download Manager is free, with no ads. Plus and Pro are paid Patreon memberships.

Do I need an account?

Not for Basic, and not for Lexi Download Manager: no account, no sign-in. Plus and Pro are Patreon memberships, so for those you sign in with Patreon inside the app.

Where do translations go?

Into the game's tl/ folder. A backup is made first.

Which languages does the interface speak?

The interface of Lexi Ren'Py Translator is available in 11 languages: English, Turkish, Russian, Chinese, Japanese, Spanish, Brazilian Portuguese, German, French, Korean and Polish.

What do Plus and Pro add?

Plus ($7 / month) is everything in Basic, plus AI translation with your own API key. Pro ($12 / month) is everything in Plus, plus Lexi credits, which are coming soon. An optional 3-day Plus trial is available once per computer.

Can I use one license on two computers?

No. One license = one computer.
