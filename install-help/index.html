Help / Windows install

Windows warned you? That is normal.

Our Windows apps (Lexi Game Translator, Lexi Download Manager and LexiDictate) are not code-signed yet, so Windows and your browser may show a warning the first time. Here is exactly what you will see and what to click.

  1. Download only from the official GitHub Releases

    This is the one rule that really matters. Get the installer only from these official pages (open the newest release, then download the .exe under “Assets”):

    • Lexi Game Translatorgithub.com/lexi-apps/lexi-renpy-translator/releases/latest
    • Lexi Download Managergithub.com/lexi-apps/lexi-download-manager/releases/latest
    • LexiDictategithub.com/lexi-apps/lexi-dictate/releases/latest

  2. Browser warning: choose Keep

    Chrome or Edge may say the file “isn’t commonly downloaded”. This only means few people have downloaded this exact file so far. It is not a virus detection. In Edge open the downloads panel, click the … menu next to the file, choose Keep, then if asked Show more → Keep anyway. In Chrome open the download’s menu (the small arrow) and choose Keep.

  3. SmartScreen: click “More info”

    When you start the installer, a blue window says “Windows protected your PC”. At first only Don’t run is visible. Do not click it; click the small More info link in the text instead.

  4. Click “Run anyway”

    After More info, the app details and a new Run anyway button appear next to Don’t run. Click Run anyway and the installer starts. This allows only this one file; Windows protection stays on for everything else.

    No “Run anyway” button? Your PC may be managed by an organization (school or work) that blocks it. Otherwise right-click the file → Properties → tick Unblock → OK, then run it again.

  5. Optional: check the file fingerprint (SHA-256)

    If a release page lists a SHA-256 value for the installer, you can compare it with your download. Open PowerShell and run (change the path to your file):

    Get-FileHash "$env:USERPROFILE\Downloads\your-installer.exe" -Algorithm SHA256

    If the Hash shown matches the one on the release page, the file is unchanged. Note: the SHA256SUMS.txt file in Lexi Download Manager releases covers the bundled open-source tools, not necessarily the installer itself.

  6. Why does this happen?

    Windows SmartScreen judges files by reputation. A code-signing certificate is paid, and Lexi apps are not signed yet, so every new installer looks “unrecognized” to Windows. This does not mean Windows found a virus. Reputation grows as more people run a file, so the warning can fade over time.

    Lexi apps are free, with no ads and no account, and the installers contain no tracking pixels, telemetry beacons or bundled third-party adware.
