01 / Privacy Policy / English

Your games, your choice of service.

Lexi Game Translator works on the games on your own computer. The text lines being translated go only to the translation service you choose, directly from your computer. Lexi Apps receives only what a Plus/Pro license check needs and the problem reports you decide to send.

Last updated / 25 November 2026

What Lexi Apps receives

  • With the free Basic plan: nothing. Basic needs no sign-in and does not contact the Lexi license server.
  • For a trial or a Plus/Pro license: your machine code and, if you sign in with Patreon, your Patreon user ID and membership status (see “License verification” below).
  • Problem reports, only when you send one yourself.
  • Lexi Apps never receives your game files, the game text, your translations or your AI/translation API keys. The app has no analytics, no tracking and no advertising.

What stays on your computer

  • Settings in your Windows user registry under HKCU\Software\RenpyTranslator: your preferences, recently used game folders and engine detection results, and your license key.
  • App folder %LOCALAPPDATA%\renpy_translator: a copy of the license (license.json), the diagnostic log (logs\lexi.log, rotating, secrets masked), your game library list, saved translations, and helper tools Lexi downloads (such as the Ren'Py SDK). A small state file may also be kept in %LOCALAPPDATA%\Lexi.
  • Inside each game folder: the translation files Lexi writes, backups that let you undo its changes, and the translation memory (_rt_cache.rtcache).
  • Interface preferences such as theme, wallpaper and cover settings are kept in the app's own local storage.
  • API keys you type into the API key box are kept in memory only while Lexi is open; they are not written to settings, profiles or logs. If you press “Save key” for OpenAI, that key is stored in Windows Credential Manager (entry Lexi/openai/default) and can be removed with “Delete key”.
  • The live translation bridge used for some Unity and Unreal games listens only on your own computer (127.0.0.1).

What is sent to translation services and why

  • To translate, Lexi sends the text lines from the game, together with translation instructions. With AI services, the “Context” setting (default: speaker and scene) also sends the speaker's name and a few earlier lines of the scene; you can turn it off.
  • Text goes directly from your computer to the service you select, with your own API key where the service needs one. Paid services bill you directly.
  • Machine translation: Google Translate and Microsoft Edge Translator (free, no key); Microsoft Translator (Bing) and Yandex Translate (with your own key).
  • AI services (Plus/Pro, your own key): OpenAI, Anthropic (Claude), Google Gemini, Groq, Mistral, OpenRouter, DeepSeek, Cerebras, OpenCode Go, or an OpenAI-compatible address you enter yourself.
  • Local engines (Ollama, LM Studio, llama.cpp) run on your own computer; with them the text stays on your computer unless you enter a remote address.
  • The optional in-game “Instant free translation (Google)” (off by default) sends untranslated lines from the running game to Google Translate while you play.
  • Each service handles the text under its own privacy policy and terms. Please read them before you choose a service.

Helper tool downloads

  • When a feature needs it, Lexi downloads the official Ren'Py SDK from renpy.org, and tools such as BepInEx, XUnity.AutoTranslator, UE4SS or llama.cpp from their GitHub release pages. These sites see a normal download request (for example your IP address).

Updates

  • If “Check automatically at startup” is on (the default), Lexi downloads a small release information file from Lexi's GitHub releases page, at most once a day, shortly after it opens.
  • Updates come only from Lexi's own GitHub releases and are checked (digital signature and SHA-256) before installing. Like any web request, GitHub sees your IP address. You can turn automatic checks off.

License verification (trial, Plus and Pro)

  • Machine code: a 16-character code made on your computer with a one-way hash (SHA-256 with a fixed salt) of your computer's hardware ID or Windows machine ID (fallback: computer name and network adapter address). Only the code is sent, never the original identifiers.
  • Trial: when you start the trial, Lexi sends the machine code to the Lexi license server (lexi-lisans.lexi-apps-dm.workers.dev, run on Cloudflare).
  • Patreon sign-in: your browser opens the license server with your machine code and a random session ID, then Patreon's sign-in page. With the “identity” permission, Patreon gives the server your Patreon user ID and your membership details for the Lexi Apps page (status, tier and billing dates). The server does not ask Patreon for, or store, your name or email address.
  • Automatic renewal: when a Patreon license has less than 7 days left, Lexi sends the machine code and the current license key to the server to get a renewed key.
  • Stored on the server: machine code, Patreon user ID, tier, license dates, the Patreon access-renewal token (encrypted), and a salted hash of your IP address (used only to limit abuse of trials and sign-ins). Sign-in sessions are deleted once the result is delivered. The license key itself is checked on your computer, offline.
  • How long: license records have no automatic deletion date; they are kept so your license and trial can be checked. To have your record deleted, email lexiapps@protonmail.com.

Problem reports

  • A report is sent only when you press Send in “Report a problem”. After a crash, Lexi asks you first.
  • It contains your description, an optional reply email, the app, Windows, Python and Qt versions, the interface language, the selected translation service, your license tier (not the key), crash details if you send a crash report, and the last lines of the diagnostic log.
  • API keys, license keys, tokens, your Windows user name, other email addresses and IP addresses are masked before sending. The log can still contain names of game folders and files. The preview shows exactly what will be sent.
  • Reports go to the Lexi Apps report service (running on Cloudflare), which stores them as issues in a private GitHub repository for the developer. Your reply email is used only to answer your report.

Third-party services

  • The translation services listed above, only the ones you choose.
  • Patreon: membership sign-in for Plus/Pro. Cloudflare: runs the license server and the report service. GitHub: updates, tool downloads and storage of problem reports. renpy.org: Ren'Py SDK downloads.
  • Each of these has its own privacy policy. Links to the website, Discord, Patreon or Buy Me a Coffee only open in your browser.

Children

  • Lexi Game Translator is a general-purpose tool and is not directed at children. Lexi Apps does not knowingly collect personal data from children.

Your choices and deleting your data

  • Use the free Basic plan without signing in, choose a local engine to keep text on your computer, turn off the “Context” setting, and turn off automatic update checks.
  • Uninstalling removes only the program files. To remove all local data, also delete the registry key HKCU\Software\RenpyTranslator, the folders %LOCALAPPDATA%\renpy_translator and %LOCALAPPDATA%\Lexi, the Windows Credential Manager entry Lexi/openai/default (or use “Delete key” in the app), and the Lexi files inside your game folders.
  • Deleting local data does not reset the trial: the trial record is linked to the machine code on the server.
  • For questions about the license records linked to your computer or Patreon account, or about a report you sent, email us.

Changes to this policy

  • If the app's data handling changes, we will update this page and the “Last updated” date above.

Contact

  • Lexi Apps: lexiapps@protonmail.com

02 / Gizlilik Politikası / Türkçe

Oyunlarınız sizde, servisi siz seçersiniz.

Lexi Game Translator, kendi bilgisayarınızdaki oyunlar üzerinde çalışır. Çevrilecek metin satırları, doğrudan bilgisayarınızdan yalnız sizin seçtiğiniz çeviri servisine gider. Lexi Apps'e yalnız Plus/Pro lisans denetiminin gerektirdiği bilgiler ve göndermeye karar verdiğiniz sorun raporları ulaşır.

Son güncelleme / 25 Kasım 2026

Lexi Apps'e ne ulaşır

  • Ücretsiz Basic planda: hiçbir şey. Basic giriş gerektirmez ve Lexi lisans sunucusuna bağlanmaz.
  • Deneme ya da Plus/Pro lisansı için: makine kodunuz ve Patreon ile giriş yaparsanız Patreon kullanıcı kimliğiniz ile üyelik durumunuz (aşağıdaki “Lisans doğrulama” bölümüne bakın).
  • Sorun raporları; yalnız kendiniz gönderdiğinizde.
  • Oyun dosyalarınız, oyun metinleri, çevirileriniz ve AI/çeviri API anahtarlarınız Lexi Apps'e hiçbir zaman ulaşmaz. Uygulamada analitik, izleme ve reklam yoktur.

Bilgisayarınızda kalanlar

  • Ayarlar, Windows kullanıcı kayıt defterinizde HKCU\Software\RenpyTranslator altında: tercihleriniz, son kullandığınız oyun klasörleri ve motor algılama sonuçları ile lisans anahtarınız.
  • Uygulama klasörü %LOCALAPPDATA%\renpy_translator: lisansın bir kopyası (license.json), tanılama günlüğü (logs\lexi.log; dönerek yenilenir, gizli bilgiler maskelenir), oyun kütüphanesi listeniz, kayıtlı çevirileriniz ve Lexi'nin indirdiği yardımcı araçlar (örneğin Ren'Py SDK). %LOCALAPPDATA%\Lexi klasöründe de küçük bir durum dosyası tutulabilir.
  • Her oyunun kendi klasöründe: Lexi'nin yazdığı çeviri dosyaları, değişiklikleri geri almanızı sağlayan yedekler ve çeviri hafızası (_rt_cache.rtcache).
  • Tema, duvar kâğıdı ve kapak ayarları gibi arayüz tercihleri uygulamanın kendi yerel depolamasında tutulur.
  • API anahtarları: API anahtarı kutusuna yazdığınız anahtarlar yalnız Lexi açıkken bellekte tutulur; ayarlara, profillere ya da günlüklere yazılmaz. OpenAI için “Anahtarı kaydet”e basarsanız bu anahtar Windows Kimlik Bilgileri Yöneticisi'nde (Lexi/openai/default kaydı) saklanır ve “Anahtarı sil” ile kaldırılabilir.
  • Bazı Unity ve Unreal oyunlarında kullanılan canlı çeviri köprüsü yalnız kendi bilgisayarınızda (127.0.0.1) dinler.

Çeviri servislerine ne gönderilir, neden

  • Çeviri için Lexi, oyundaki metin satırlarını çeviri talimatlarıyla birlikte gönderir. AI servislerinde “Bağlam” ayarı (varsayılan: konuşan karakter ve sahne) konuşan karakterin adını ve sahnedeki önceki birkaç satırı da gönderir; bu ayarı kapatabilirsiniz.
  • Metin, doğrudan bilgisayarınızdan seçtiğiniz servise gider; servis anahtar istiyorsa sizin API anahtarınız kullanılır. Ücretli servisler ücreti doğrudan size yansıtır.
  • Makine çevirisi: Google Çeviri ve Microsoft Edge Çevirmeni (ücretsiz, anahtarsız); Microsoft Translator (Bing) ve Yandex Çeviri (kendi anahtarınızla).
  • AI servisleri (Plus/Pro, kendi anahtarınızla): OpenAI, Anthropic (Claude), Google Gemini, Groq, Mistral, OpenRouter, DeepSeek, Cerebras, OpenCode Go ya da kendiniz girdiğiniz OpenAI uyumlu bir adres.
  • Yerel motorlar (Ollama, LM Studio, llama.cpp) kendi bilgisayarınızda çalışır; uzak bir adres girmediğiniz sürece metin bilgisayarınızdan çıkmaz.
  • İsteğe bağlı oyun içi “Anında ücretsiz çeviri (Google)” özelliği (varsayılan kapalı), siz oynarken çalışan oyundaki çevrilmemiş satırları Google Çeviri'ye gönderir.
  • Her servis metni kendi gizlilik politikası ve koşullarına göre işler. Bir servisi seçmeden önce lütfen bunları okuyun.

Yardımcı araç indirmeleri

  • Bir özellik gerektirdiğinde Lexi, resmî Ren'Py SDK'yı renpy.org'dan; BepInEx, XUnity.AutoTranslator, UE4SS ya da llama.cpp gibi araçları da kendi GitHub sürüm sayfalarından indirir. Bu siteler sıradan bir indirme isteği görür (örneğin IP adresinizi).

Güncellemeler

  • “Açılışta otomatik denetle” açıksa (varsayılan), Lexi açıldıktan kısa süre sonra, günde en çok bir kez, Lexi'nin GitHub sürüm sayfasından küçük bir sürüm bilgisi dosyası indirir.
  • Güncellemeler yalnız Lexi'nin kendi GitHub sürümlerinden gelir ve kurulmadan önce doğrulanır (dijital imza ve SHA-256). Her web isteğinde olduğu gibi GitHub IP adresinizi görür. Otomatik denetimi kapatabilirsiniz.

Lisans doğrulama (deneme, Plus ve Pro)

  • Makine kodu: bilgisayarınızın donanım kimliğinden ya da Windows makine kimliğinden (bunlar okunamazsa bilgisayar adı ve ağ kartı adresinden) tek yönlü bir özetle (sabit tuzlu SHA-256) bilgisayarınızda üretilen 16 karakterlik koddur. Yalnız bu kod gönderilir; asıl kimlikler hiçbir zaman gönderilmez.
  • Deneme: denemeyi başlattığınızda Lexi, makine kodunu Lexi lisans sunucusuna (lexi-lisans.lexi-apps-dm.workers.dev, Cloudflare üzerinde çalışır) gönderir.
  • Patreon ile giriş: tarayıcınız, makine kodunuz ve rastgele bir oturum kimliğiyle lisans sunucusunu, ardından Patreon'un giriş sayfasını açar. Patreon, “identity” (kimlik) izniyle sunucuya Patreon kullanıcı kimliğinizi ve Lexi Apps sayfasındaki üyelik bilgilerinizi (durum, seviye ve ödeme tarihleri) verir. Sunucu Patreon'dan adınızı ya da e-posta adresinizi istemez ve saklamaz.
  • Otomatik yenileme: Patreon lisansının bitmesine 7 günden az kaldığında Lexi, yenilenmiş anahtarı almak için makine kodunu ve mevcut lisans anahtarını sunucuya gönderir.
  • Sunucuda saklananlar: makine kodu, Patreon kullanıcı kimliği, seviye, lisans tarihleri, Patreon erişim yenileme jetonu (şifreli) ve IP adresinizin tuzlu bir özeti (yalnız deneme ve giriş kötüye kullanımını sınırlamak için). Giriş oturumları, sonuç teslim edilince silinir. Lisans anahtarının kendisi bilgisayarınızda, çevrimdışı denetlenir.
  • Ne kadar süre: lisans kayıtlarının otomatik silinme tarihi yoktur; lisansınızın ve denemenizin denetlenebilmesi için tutulur. Kaydınızın silinmesini isterseniz lexiapps@protonmail.com adresine yazın.

Sorun raporları

  • Rapor yalnız “Sorun bildir” penceresinde Gönder'e bastığınızda gönderilir. Bir çökmeden sonra Lexi önce size sorar.
  • Raporda açıklamanız, isteğe bağlı yanıt e-postanız, uygulama, Windows, Python ve Qt sürümleri, arayüz dili, seçili çeviri servisi, lisans seviyeniz (anahtar değil), çökme raporu gönderiyorsanız çökme ayrıntıları ve tanılama günlüğünün son satırları bulunur.
  • Göndermeden önce API anahtarları, lisans anahtarları, jetonlar, Windows kullanıcı adınız, başka e-posta adresleri ve IP adresleri maskelenir. Günlükte yine de oyun klasörü ve dosya adları bulunabilir. Önizleme, gönderilecek metnin aynısını gösterir.
  • Raporlar Lexi Apps rapor hizmetine (Cloudflare üzerinde çalışır) gider ve geliştirici için gizli bir GitHub deposunda kayıt (issue) olarak saklanır. Yanıt e-postanız yalnız raporunuza cevap vermek için kullanılır.

Üçüncü taraf hizmetler

  • Yukarıda sayılan çeviri servislerinden yalnız sizin seçtikleriniz.
  • Patreon: Plus/Pro için üyelik girişi. Cloudflare: lisans sunucusunu ve rapor hizmetini çalıştırır. GitHub: güncellemeler, araç indirmeleri ve sorun raporlarının saklanması. renpy.org: Ren'Py SDK indirmeleri.
  • Bunların her birinin kendi gizlilik politikası vardır. Web sitesi, Discord, Patreon ya da Buy Me a Coffee bağlantıları yalnız tarayıcınızda açılır.

Çocuklar

  • Lexi Game Translator genel amaçlı bir araçtır ve çocuklara yönelik değildir. Lexi Apps çocuklardan bilerek kişisel veri toplamaz.

Seçenekleriniz ve verilerinizi silme

  • Ücretsiz Basic planı giriş yapmadan kullanabilir, metnin bilgisayarınızda kalması için yerel bir motor seçebilir, “Bağlam” ayarını ve otomatik güncelleme denetimini kapatabilirsiniz.
  • Uygulamayı kaldırmak yalnız program dosyalarını siler. Bilgisayarınızdaki tüm verileri silmek için ayrıca HKCU\Software\RenpyTranslator kayıt defteri anahtarını, %LOCALAPPDATA%\renpy_translator ve %LOCALAPPDATA%\Lexi klasörlerini, Windows Kimlik Bilgileri Yöneticisi'ndeki Lexi/openai/default kaydını (ya da uygulamadaki “Anahtarı sil” düğmesini) ve oyun klasörlerinizdeki Lexi dosyalarını silin.
  • Yerel verileri silmek denemeyi sıfırlamaz: deneme kaydı sunucuda makine koduna bağlıdır.
  • Bilgisayarınıza ya da Patreon hesabınıza bağlı lisans kayıtları veya gönderdiğiniz bir rapor hakkındaki sorularınız için bize e-posta yazın.
