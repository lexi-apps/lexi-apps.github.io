01 / LEXI GAME TRANSLATOR / WORKFLOW & SHOWCASE

Three clicks to play.

Drop any supported game folder. Lexi detects the engine, configures Autopilot & font patches where needed, backs up first, and translates with full resume support.

How it works

  1. 01

    Drop the game folder

    Lexi auto-detects 18 engines — Ren'Py, RPG Maker 2000–MZ, Unity, Unreal 4/5, Godot 3/4, Tyrano, WOLF RPG, KiriKiri, QSP, HTML/Twine, GameMaker, and SRPG Studio.

  2. 02

    Choose language & engine

    Use free built-in machine translation in Basic, or connect your own cloud/local AI key in Plus. Autopilot sets up Unity & Unreal bridges and patches fonts automatically.

  3. 03

    Translate & play

    A backup is created before writing. Character names and tags stay protected, interrupted runs resume from the exact line, and you can launch straight from the Game Shelf.

FAQ / GAME TRANSLATOR

Short answers.

Which game engines are supported?

18 engines: Ren'Py, RPG Maker (2000/2003, XP, VX, VX Ace, MV, MZ), Unity (Mono & IL2CPP), Unreal Engine 4 & 5, Godot 3 & 4, Tyrano, WOLF RPG, KiriKiri, QSP, HTML/Twine, GameMaker, and SRPG Studio.

Where do translations go, and can I undo them?

Lexi writes translations in each engine's native format (such as Ren'Py's tl/ folder, RPG Maker data files, or Unity/Unreal Live Bridge files) and creates an automatic local backup beforehand so you can restore in one click.

Windows says “Windows protected your PC”. What do I do?

Click More info, then Run anyway. It appears because the installer is not code-signed yet (code-signing certificates are paid). Always download from our official GitHub releases. Step-by-step guide.

Can I use one Plus/Pro license on two computers?

No. One license = one computer.
