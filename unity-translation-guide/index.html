How to translate a Unity game, step by step.

Unity is one of the most popular engines for indie and commercial games — and one of the hardest to translate, because the text is usually packed inside compiled files. This guide explains why, and shows how Lexi Game Translator's Autopilot sets up the free open-source tools BepInEx and XUnity.AutoTranslator for you, pre-translates the packed text and translates new lines live while you play — without editing the game's own files.

Why translating a Unity game is tricky

A Unity game has no single script file you can open and edit. Its text can sit in three very different places:

Localization files

Some games ship readable .po, .csv or .json language files, usually under <Game>_Data/StreamingAssets. These are the easy case.

Packed assets

Most dialogue and UI text is serialized into binary .assets files or asset bundles such as data.unity3d, often compressed.

Compiled code

Text written straight into the game's code ends up in Assembly-CSharp.dll (Mono builds) or in global-metadata.dat next to GameAssembly.dll (IL2CPP builds).

Fonts

Unity games — especially those using TextMeshPro — often include only the letters the developer needed, so new letters show up as empty boxes.

Editing these files directly is risky and breaks with every game update. The proven approach is a runtime translator: BepInEx loads XUnity.AutoTranslator into the game, which replaces text on screen with translations from plain text files. Setting that up by hand means picking the right BepInEx build for Mono or IL2CPP and 32 or 64 bit, editing an INI file and collecting the text — this is exactly what Lexi's Autopilot automates.

Before you start

  • A PC with Windows 10 or 11 (64-bit). The installer does not need administrator rights.
  • The game installed on your PC — the folder with the game's .exe and its <Game>_Data folder. You can drop the folder or the .exe onto the Lexi window.
  • A single-player game. Games with anti-cheat (for example EasyAntiCheat or BattlEye) are detected and the automatic setup is blocked — mod loaders do not belong in online games.
  • An internet connection: once, to download BepInEx and XUnity.AutoTranslator from their official sources after you approve it, and for the online translation engines.

Translate a Unity game with Lexi Game Translator

  1. Download and install the app

    Lexi Game Translator is a free app for Windows 10 and 11 (64-bit). Download the installer from the official GitHub Releases page and run it. If Windows SmartScreen shows a blue warning the first time, the install help page shows what to click.

  2. Pick or drop the game folder

    Lexi recognizes Unity and whether the game is a Mono or an IL2CPP build, checks for anti-cheat and shows an Autopilot card that tells you what the game needs. If the game already ships readable localization files, no plugin is needed at all: Lexi translates those files directly — skip to step 3 and press Translate.

  3. Choose your target language and translation engine

    Pick your target language from 30+ supported languages. The keyless Google + Microsoft Edge chain is free in Basic; Bing and Yandex work with your own API key, and Lexi Pro adds cloud AI with your own key or offline local models (Ollama, LM Studio, llama.cpp). Paid cloud AI always shows an estimate and waits for your approval first.

  4. Press Prepare & Translate

    For a packed game, the Autopilot button Prepare & Translate runs three steps:

    1. Plugin

    After you approve the download, the matching official BepInEx and XUnity.AutoTranslator packages are downloaded, checked against known SHA-256 fingerprints and installed into the game folder.

    2. Extract packed texts

    Lexi reads text from .assets files and bundles, Assembly-CSharp.dll or global-metadata.dat — read-only — and filters out technical noise.

    3. Translate

    The lines are translated with your engine and written as XUnity translation files under BepInEx/Translation/<language>/Text/.

    The game's own .assets, bundle, .dll and .dat files are never written to. Every file the plugin setup adds is recorded, and any existing file it would replace is backed up first.

  5. Launch the game with Live Bridge

    Not every line can be found in advance — names you type, generated messages, text loaded later. Press Launch Game with Live Bridge: Lexi starts a small local server on 127.0.0.1 (it accepts no outside connections), and any new text XUnity.AutoTranslator meets while you play is translated with your chosen engine and glossary and saved for next time. The bridge stops automatically when the game closes.

Fonts and empty boxes

If translated text shows empty boxes, the game's font does not contain your letters. XUnity.AutoTranslator can swap fonts at runtime: for classic Unity UI text it uses an override font, and for TextMeshPro text it needs a TextMeshPro font asset that contains your letters, placed in BepInEx's font folder and set as the fallback font. In the Live Translation Bridge panel, Inspect shows whether the game uses TextMeshPro, which TextMeshPro fonts are present, whether the fallback font is set and whether any translation file has the wrong encoding; Apply INI writes the settings. Lexi does not download fonts for Unity games, so a TextMeshPro font with your letters is something you add yourself.

Practical tips

Play a little first
Extraction finds most text, but some only appears in play. A first session with Live Bridge fills in menus, names and messages; Lexi keeps those translations, so they are not sent to the engine again.
Quality & CSV
The Quality and editing page finds empty, untranslated or broken lines; you can fix any line in the built-in editor or export/import CSV. Rich-text tags such as <color=…> and placeholders such as {0} are kept as they are.
Removing the plugin
Uninstall removes every BepInEx and XUnity file Lexi installed and puts back any file it had replaced. Your translations in BepInEx/Translation are kept.
Game updates
After an update, open the game in Lexi again and run the Autopilot. Finished lines come back from the translation memory, so only new text goes to the engine.

Personal use and sharing

A translation made this way is for your own use. The game's story, text and art belong to its developer, so before you share a translated patch publicly (for example with Lexi's patch .zip export), ask the developer for permission. Use mod loaders only in single-player games.

FAQ / Unity translation

Short answers.

Is Lexi Game Translator free?

Yes. The Basic tier is free, needs no account or sign-in, and translates with the keyless built-in Google and Microsoft Edge chain (plus Bing and Yandex if you provide your own API key). AI translation is optional and unlocked with Lexi Pro ($6/month on Patreon), with a one-time 3-day free AI trial per computer. BepInEx and XUnity.AutoTranslator are free open-source tools.

Does it work with Mono and IL2CPP games?

Yes. Lexi detects whether a Unity game uses Mono or IL2CPP and whether it is 32- or 64-bit, and installs the matching official BepInEx and XUnity.AutoTranslator packages after you approve the download.

Does Lexi modify the game's own files?

No. The .assets, bundle, .dll and global-metadata.dat files are only read, never written. Lexi adds the BepInEx and XUnity.AutoTranslator files to the game folder, records every file it installs, backs up any file it would replace, and removes them all with Uninstall while keeping your translations.

Can I translate online games or games with anti-cheat?

No. If Lexi finds anti-cheat software such as EasyAntiCheat or BattlEye in the game folder, automatic plugin setup is blocked. Mod loaders like BepInEx are meant for single-player games.

Letters show as boxes. What can I do?

Unity games only contain the letters their developer needed. Lexi's Unity check shows whether the game uses TextMeshPro and whether XUnity.AutoTranslator has a fallback font set. For TextMeshPro games you need a TextMeshPro font asset that contains your letters in the BepInEx font folder; Lexi does not download fonts for Unity games.

Do I need the internet while playing?

Lines that were already translated are loaded from files in the game folder. New text that appears while you play is translated through the Live Bridge with the engine you selected: online engines need the internet, while a local AI model in Lexi Pro works offline.

Can I share my translation with others?

Lexi can export a translation patch as a .zip file, but the game's text belongs to its developer. Translate for your own use, and ask the developer for permission before you share a translated patch publicly.
