How to translate a Ren'Py game, step by step.

Many visual novels are made with Ren'Py. This guide shows how to translate a Ren'Py game into your own language for free with Lexi Game Translator, a Ren'Py translator for Windows, without breaking the game's text tags, variables or menus.

Why translating a Ren'Py game is tricky

A Ren'Py game keeps its story in script files (.rpy). Released games usually ship them only in compiled form (.rpyc), often packed inside .rpa archives. A single line of dialogue can look like this:

e "Welcome back, {b}[player_name]{/b}! You have [gold] coins."

Only the words should be translated. {b}…{/b} is a text tag (bold), while [player_name] and [gold] are variables that the game fills in as you play. If a translation service changes or drops them (for example, turning [gold] into [oro] on the way to Spanish), the line shows garbage or Ren'Py stops with an error. Menu choices, button texts and character names need the same care: a heroine called Rose should not turn into a flower.

Ren'Py has its own system for extra languages: translation files in the game's tl folder plus an in-game language setting. Lexi Game Translator writes your translation into exactly this system, so the original story files stay as they are.

Before you start

  • A PC with Windows 10 or 11 (64-bit). The installer does not need administrator rights.
  • The game installed on your PC: select the folder containing game, or drag and drop the game folder or its .exe file straight onto the Lexi window.
  • Some free disk space. Lexi makes a verified copy of the whole game folder before every translation (keeping the last three unlocked backups by default, plus auto-locking your first original backup), so a large game needs roughly the same space again per backup. You can adjust the backup count in Backups and memory.
  • An internet connection for the online translation engines (or a local AI model with Ollama, LM Studio, or llama.cpp for offline translation in Lexi Pro).

Translate a Ren'Py game with Lexi Game Translator

  1. Download and install the app

    Lexi Game Translator is a free app for Windows 10 and 11 (64-bit) with 12 built-in interface languages (including Turkish and right-to-left Arabic) plus dark and light themes. Download the installer from the official GitHub Releases page and run it. The installer is not code-signed yet, so Windows SmartScreen may warn you the first time; the install help page shows exactly what to click.

  2. Pick or drop the game folder

    On first launch the Quick start wizard opens; you can also start it any time from the app's Guide page, or simply drag and drop the game folder or its .exe file onto the window. Lexi auto-detects Ren'Py (along with 17 other supported game engines) and scans it right away, counting every line, including scripts in .rpa archives and compiled .rpyc files. Scanning does not change any files.

  3. Choose the target language and engine

    Pick your target language from 30+ supported languages. The default engine in Basic is completely free and keyless: Google and Microsoft Edge working together in parallel, with automatic fallback if one is rate-limited. Basic also includes Bing / Microsoft Translator and Yandex Translate if you provide your own API key. Optional AI translation — 1-click cloud presets (Gemini, Groq, Mistral, OpenRouter, DeepSeek, Claude, Cerebras, plus OpenAI) with your own key, or local offline models (Ollama, LM Studio, llama.cpp) — is unlocked in Lexi Pro on Patreon ($6/month, with a one-time 3-day free AI trial per computer). Before any paid job starts, Lexi shows the estimated cost, asks for your approval, and lets you set a spending cap.

  4. Start the translation

    Press Translate and wait. Before anything is written, Lexi makes a verified full copy of the game's game folder as a backup. Tags, variables and character names are protected while the text is translated. You can pause or stop at any time: finished lines are kept in the translation memory, and the next run continues where it stopped.

    The translation goes into game/tl/<language>/, and a small language-switcher script is added to the game folder. The game's own script files are not edited. Lexi also checks fonts on disk and inside .rpa archives and adds a bundled fallback font automatically whenever your target language's letters are missing (and writes RTL support for right-to-left languages). If the game includes .srt or .vtt video subtitles, you can translate them in the same run without touching timestamps.

  5. Launch the game and switch the language

    When the translation is ready, press Open game (or launch it any time later from the Game Shelf). In the game's main menu, press the Language button with the globe icon and choose your language. While playing, Shift+L switches between the translation and the original text without closing the game.

Tips for a better translation

Glossary & context
Lexi reads character names from the game's scripts and lists them under Suggested character names. Add them to the Glossary so they stay unchanged, and set fixed translations for recurring terms so they read the same everywhere. For AI engines, Lexi also builds an offline Context Bible of speakers and character notes automatically.
Quality & CSV
The Quality and editing page finds lines that are empty, untranslated, still in English or have broken tags. Retranslate problems sends only those lines again, and you can edit any line directly in the app or export/import CSV to review translations in Excel or LibreOffice.
Game updates
When a new version of the game comes out, scan and translate it again. Every finished line is kept in the translation memory, so unchanged lines come back instantly and only new or changed lines go to the engine. Lexi also keeps a local copy under Saved translations so your work survives uninstalling or replacing the game folder.
Backups
Something looks wrong? Open Backups and memory and press Restore: the whole game folder goes back to the chosen date, and a safety backup of its current state is made first. By default the last three unlocked backups are kept (adjustable from 0 to 10), your first original backup is locked automatically, and you can lock any other backup to keep it for good.
Mods, subtitles & batch
Under Tools, Lexi can also translate Ren'Py mods (.rpy / .rpa) with automatic rollback backup, translate .srt/.vtt video subtitles, export a 1-click patch .zip, and queue multiple games for unattended translation using the free engines.
18 game engines
Although this guide focuses on Ren'Py, the same app auto-detects 18 engines in total — including RPG Maker (2000–MZ), Unity (Mono & IL2CPP), Unreal Engine 4 & 5, Godot 3 & 4, Tyrano, WOLF RPG, KiriKiri, QSP, HTML/Twine, GameMaker, and SRPG Studio. See the Lexi Game Translator page for details.

Personal use and sharing

A translation made this way is for your own use. The game's story, text and art belong to its developer, so before you share a translated patch publicly (for example with Lexi's patch .zip export), ask the developer for permission.

FAQ / Ren'Py translation

Short answers.

Is Lexi Game Translator free?

Yes. The Basic tier is free, needs no account or sign-in, and translates with the keyless built-in Google and Microsoft Edge chain (plus Bing and Yandex if you provide your own API key). AI translation is optional and unlocked with Lexi Pro ($6/month on Patreon), with a one-time 3-day free AI trial per computer.

Will it change or damage my game files?

The game's own script files are not edited. Lexi writes translation files into game/tl/<language>/ and adds a small language-switcher script, and it makes a verified full backup of the game folder before every translation (automatically locking your first original backup), so you can go back with one click. In free Basic the in-game language menu shows a small “Translated with Lexi” line, which can be turned off in Lexi Pro or during the 3-day trial.

Which Ren'Py games work?

Ren'Py 7 and Ren'Py 8 games, including released games that ship only compiled .rpyc scripts inside .rpa archives, plus optional .srt/.vtt video subtitles and Ren'Py mods. Lexi Game Translator also auto-detects 18 game engines in total, including RPG Maker, Unity, Unreal Engine, Godot, Tyrano, WOLF RPG, KiriKiri, QSP, HTML/Twine, GameMaker, and SRPG Studio; see the product page for the full list.

Do I need an internet connection or an API key?

The default free engine (Google and Microsoft Edge working together) works online and needs no API key. Bing and Yandex are also available in Basic using your own API key. Cloud AI presets in Lexi Pro use your own API key, while local AI models (Ollama, LM Studio, or llama.cpp) run offline on your own computer once downloaded.

Can I switch back to the original language?

Yes. Use the Language button in the game's main menu, or press Shift+L while playing to switch between the translation and the original text.

What if the translation stops halfway?

Nothing is lost. Finished lines are kept in the translation memory, and when you start again Lexi continues where it stopped, so finished work is never paid for twice.

The game shows empty boxes instead of letters. What can I do?

Usually nothing. Lexi checks the game's fonts (including fonts packed inside .rpa archives) for your target language's characters and automatically adds a bundled fallback font when letters are missing, covering Turkish and European accented Latin, Cyrillic, Greek, Vietnamese, Japanese, Korean, Chinese, Thai, Hindi, and right-to-left scripts.

Can I share my translation with others?

Lexi can export a translation patch as a .zip file, but the game's text belongs to its developer. Translate for your own use, and ask the developer for permission before you share a translated patch publicly.
