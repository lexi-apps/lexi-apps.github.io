Guide / Unreal Engine / Step by step

How to translate an Unreal Engine game, step by step.

Unreal Engine 4 and 5 games keep their text in packed archives — or show it only while the game runs. This guide explains where that text lives, which Unreal games can be translated, and how to translate one into your language for free with Lexi Game Translator: without rewriting the game's original .pak files and without breaking variables such as {PlayerName}.

Why translating an Unreal Engine game is tricky

A released Unreal game has no script file you can simply open. Its text ends up in one of two places, and Lexi handles each one differently:

Open localization tables

Many games ship their text as binary .locres tables (sometimes Gettext .po files) under Content/Localization/ — either loose on disk or packed inside a .pak archive in Content/Paks/. Lexi can read these when the archive is not encrypted.

Closed games

Other games keep text in encrypted archives, in IoStore containers (.utoc/.ucas), behind compression that cannot be opened directly, or have an empty .locres. For these, Lexi reads the text while the game runs, through the free UE4SS mod loader.

On top of that, a single Unreal line can contain variables and rich-text tags:

<Bold>{PlayerName}</>, you found {Count} coins!

{PlayerName} and {Count} are filled in by the game, and <Bold>…</> styles the text. If a translator translates {PlayerName} or drops a tag, the line breaks. Lexi checks every translated line and does not write a line in which such a variable, tag or %s-style placeholder went missing.

Before you start

  • A PC with Windows 10 or 11 (64-bit). The installer does not need administrator rights.
  • A single-player game. Games with anti-cheat (EasyAntiCheat or BattlEye) are detected, and the plugin setup is blocked — mod loaders do not belong in online games.
  • The game folder on your PC — the one with the game's .exe and a <Game>/Content/Paks folder. For closed games, Lexi needs the 64-bit <Game>/Binaries/Win64/…-Win64-Shipping.exe.
  • An internet connection for the online translation engines and, once, for downloading UE4SS from its official GitHub page if your game needs it — or a local AI model with Ollama, LM Studio, or llama.cpp for offline translation in Lexi Pro.

Translate an Unreal Engine game with Lexi Game Translator

  1. Download and install the app

    Lexi Game Translator is a free app for Windows 10 and 11 (64-bit). Download the installer from the official GitHub Releases page and run it. If Windows SmartScreen shows a blue warning the first time, the install help page shows what to click.

  2. Pick the game folder and read the Autopilot card

    Select the game folder (or drop it onto the window). Lexi recognizes Unreal Engine from folders such as Content/Paks, Content/Localization or Engine/Binaries and checks — without changing anything — which of the two routes the game needs. It also looks for anti-cheat and checks the game's fonts. The Autopilot card then shows the plan:

    Open game

    Readable .locres/.po found: no plugin needed. Go straight to Translate (step 5).

    Closed game

    No readable tables: UE4SS Plugin → Font Patch (if needed) → Collect Texts → Translate.

  3. Closed games: prepare the plugin (one click)

    Press 1. Prepare (Plugin + Font Patch). Lexi asks before downloading anything. With your approval it downloads the official open-source UE4SS (MIT license) from its GitHub releases, checks the file's SHA-256 fingerprint, and installs it with Lexi's small Lua mod into the game's Binaries/Win64 folder. Every installed file is recorded, and any file it replaces is backed up. If the game's fonts lack your letters, the font patch is added in the same step (see below).

  4. Closed games: collect the texts

    Press 2. Launch & Collect Texts. Lexi starts the game once for a short time and closes it again. Meanwhile Lexi's mod reads the game's string tables, data tables and on-screen text widgets — read-only — and lists the lines it finds, which then appear in Lexi ready to translate.

  5. Choose your language and engine, then press Translate

    Pick your target language from 30+ supported languages and an engine:

    1. Free keyless (Basic)

    Google + Microsoft Edge run in parallel with automatic fallback. No account, no API key, unlimited lines.

    2. Own key machine (Basic)

    Bing / Microsoft Translator and Yandex Translate are also unlocked in Basic when you enter your own API key.

    3. Cloud & local AI (Lexi Pro)

    1-click presets for cloud AI with your own key, or offline Ollama / LM Studio / llama.cpp. Patreon $6/mo + 3-day free AI trial.

    Press Translate. Where the result goes depends on the route:

    • Tables inside a .pak: written into a separate patch file, Content/Paks/~mods/zzz_Lexi_<language>_P.pak. The game's own .pak archives are never rewritten. For IoStore games, the matching empty .utoc/.ucas companion files are added next to it.
    • Loose .locres/.po files: edited in place after a backup. If the game has a folder per language, Lexi creates the folder for your language from the source language and leaves the other languages untouched.
    • Closed games: saved into a translation file of Lexi's mod. While the game runs, the mod swaps the original text in on-screen text widgets for your translation.

  6. Play and check — with Live Bridge for new lines

    For open games, press Launch game and check the menus and dialogue. For closed games, press Launch Game with Live Bridge: lines that were already translated come from the file in the game folder, and text the collection step did not see is sent to Lexi's local bridge on your own PC (127.0.0.1), translated with your chosen engine and glossary, and shown in the game.

Fonts and missing letters

Unreal games often contain only the letters their developer needed. Translated text then shows empty boxes where letters such as ğ, ş or ı should be.

Autopilot checks the game's fonts. When Lexi's bundled font covers your language, it offers the Font Patch: an extra ~mods/zzz_Lexi_font_P.pak file that swaps the game's fonts for one that contains your letters, again without touching the original archives. For open games, the patch can be applied automatically during translation (Apply automatic font patch during translation). The patch is not offered for English or right-to-left languages, pixel-art fonts are left alone by default, and Uninstall Font Patch removes it again.

Practical tips and honest limits

Anti-cheat
If EasyAntiCheat or BattlEye is found in the game folder, Autopilot shows Anti-Cheat Blocked: UE4SS is not installed, the game is not started for text collection, and the font patch is not offered.
Encrypted & packed
Lexi reads .pak archives that are not encrypted and whose entries are stored uncompressed or with Zlib/Gzip. AES-encrypted archives, Oodle- or Zstd-compressed entries and IoStore-only text cannot be read directly — those games take the UE4SS route.
64-bit only
The UE4SS route needs the game's *-Win64-Shipping.exe and works only with 64-bit games.
What is left out
The engine's own Engine/ localization, saved and temporary folders, and graphics plugins such as DLSS, FSR or XeSS are skipped. In closed games, Lexi's mod only sees text that passes through on-screen text widgets; words drawn into textures are image pixels, not text.
Glossary & quality
Use the Glossary for names and recurring terms. The Quality and editing page finds empty, untranslated or broken lines, and you can fix any line in the built-in editor or review it as CSV.
Undo everything
Uninstall in the Live Translation Bridge card removes the UE4SS and Lexi files it installed and puts back any file it had replaced. Backups and memory restores translated files, and your first backup is locked automatically.

Personal use and sharing

A translation made this way is for your own use. The game's story, text and art belong to its developer, so before you share a translated patch publicly (for example with Lexi's patch .zip export), ask the developer for permission.

FAQ / Unreal Engine translation

Short answers.

Is Lexi Game Translator free?

Yes. The Basic tier is free, needs no account or sign-in, and translates with the keyless built-in Google and Microsoft Edge chain (plus Bing and Yandex if you provide your own API key). AI translation is optional and unlocked with Lexi Pro ($6/month on Patreon), with a one-time 3-day free AI trial per computer. UE4SS is a free open-source tool (MIT license).

Which Unreal Engine games work?

Single-player Unreal Engine 4 and 5 games for Windows. If the game ships readable localization files (.locres or .po, loose or inside an unencrypted .pak), Lexi translates them directly. Otherwise Autopilot sets up the UE4SS mod loader and collects the text while the game runs; that route needs the game's 64-bit *-Win64-Shipping.exe.

Does Lexi change the game's own files?

The game's original .pak archives are never rewritten. Translated .pak content goes into a separate patch file in Content/Paks/~mods/, and UE4SS with Lexi's mod is added next to the game's .exe. Loose .locres or .po files are edited in place. Every file Lexi replaces is backed up first, and every file it adds is recorded so it can be removed again.

Can I translate online games or games with anti-cheat?

No. If Lexi finds EasyAntiCheat or BattlEye in the game folder, the UE4SS setup and the automatic text collection are blocked, and the font patch is not offered. Mod loaders like UE4SS are meant for single-player games.

Letters show as boxes. What can I do?

Many Unreal games only include the letters their developer needed. Autopilot checks the game's fonts and, if Lexi's bundled font covers your language, offers a Font Patch: an extra patch file in ~mods/ that swaps in a font with your letters. It is not offered for English or right-to-left languages, and pixel-art fonts are left alone by default.

How do I remove UE4SS and the patches again?

In the Live Translation Bridge card, Uninstall removes the UE4SS and Lexi files it installed and puts back any file it had replaced. The font patch has its own Uninstall Font Patch button, and Backups and memory restores the translated files.

Can I share my translation with others?

Lexi can export a translation patch as a .zip file, but the game's text belongs to its developer. Translate for your own use, and ask the developer for permission before you share a translated patch publicly.
