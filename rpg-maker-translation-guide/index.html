How to translate an RPG Maker game, step by step.

RPG Maker powers thousands of indie RPGs and story games. This guide explains where an RPG Maker game keeps its text, what can go wrong when you translate it, and how to translate MV, MZ, VX Ace, VX, XP and 2000/2003 games into your language for free with Lexi Game Translator — without breaking control codes, plugin commands or the game's data files.

Why translating an RPG Maker game is tricky

RPG Maker games do not have a separate translation folder. Dialogue, choices, item and skill names, menu words and battle messages all live inside the game's own data files — and every generation stores them differently:

RPG Maker MV & MZ

JSON files in www/data/ (MV) or data/ (MZ): Map001.json, CommonEvents.json, Items.json, System.json and more. Plugin settings live in js/plugins.js. Some games pack everything into package.nw or into the .exe itself.

RPG Maker VX Ace, VX & XP

Binary Ruby files (.rvdata2, .rvdata, .rxdata) in the Data folder — in released games usually packed into one .rgss3a, .rgss2a or .rgssad archive that ordinary editors cannot open.

RPG Maker 2000 & 2003

Binary RPG_RT.ldb (database), RPG_RT.lmt (map tree) and MapXXXX.lmu (maps). Text is stored in old code pages such as Shift-JIS or Windows-1252, which cannot hold every letter of every language.

On top of that, a single message line is full of control codes:

\C[2]\N[1]\C[0], you found \V[5] gold coins!

\C[2] changes the text color, \N[1] prints the name of actor 1 and \V[5] shows the value of variable 5. If a translator drops a bracket or turns \N[1] into \n[1], the line shows the wrong name or garbage. And not every string in the data is meant to be translated: face and picture file names, plugin commands and script calls look like text but are code — translate them and the game can no longer find its images or crashes.

Lexi Game Translator knows these formats. It reads only player-facing text, keeps control codes and placeholders such as %1 exactly as they are, never touches file names, plugin commands or script calls, and refuses to write a translated line in which a code got lost.

Before you start

  • A PC with Windows 10 or 11 (64-bit). The installer does not need administrator rights.
  • The game extracted on your PC — the folder that contains Game.exe (or RPG_RT.exe for 2000/2003). You can also drag and drop the folder or its .exe straight onto the Lexi window.
  • Some free disk space: before writing, Lexi copies every file it is about to change into a backup folder inside the game folder.
  • An internet connection for the online translation engines — or a local AI model with Ollama, LM Studio, or llama.cpp for fully offline translation in Lexi Pro.
  • If the game is still being updated, translate the version you actually play. When it updates, you simply scan and translate again (see the tips below).

Translate an RPG Maker game with Lexi Game Translator

  1. Download and install the app

    Lexi Game Translator is a free app for Windows 10 and 11 (64-bit). Download the installer from the official GitHub Releases page and run it. If Windows SmartScreen shows a blue warning the first time, the install help page shows what to click.

  2. Pick or drop the game folder

    Select the game folder (or drop it, or its .exe, onto the window). Lexi recognizes the exact generation — MV, MZ, VX Ace, VX, XP or 2000/2003 — and runs a read-only scan: it counts the lines and shows which files they come from without changing anything. Packed games are read directly: NW.js packages (package.nw or a ZIP attached to the .exe) and .rgss3a / .rgss2a / .rgssad archives need no extra unpacking tool.

    What gets collected: dialogue and scrolling text, choices, speaker names (MZ), actor names and profiles, classes, items, weapons, armor, skills, states and their battle messages, enemies, map display names, menu terms from System.json, and plugin parameters that look like player-facing text. External YAML dialogue files used by some MV/MZ games are read too.

  3. Choose your target language and translation engine

    Pick your target language from 30+ supported languages and an engine:

    1. Free keyless (Basic)

    Google + Microsoft Edge run in parallel with automatic fallback. No account, no API key, unlimited lines.

    2. Own key machine (Basic)

    Bing / Microsoft Translator and Yandex Translate are also unlocked in Basic when you enter your own API key.

    3. Cloud & local AI (Lexi Pro)

    1-click presets for cloud AI with your own key, or offline Ollama / LM Studio / llama.cpp. Patreon $6/mo + 3-day free AI trial.

    Whenever a cloud AI job could incur API costs, Lexi calculates the estimated amount up front, waits for your explicit approval, and enforces any spending cap you set.

  4. Press Translate

    Press Translate and watch the lines appear live. Before anything is written, Lexi copies each file it will change into a backup folder inside the game folder and automatically locks your first backup, so the original can always be restored. You can pause or stop at any time; finished lines are kept and the next run continues from there.

    The translation is then written in place: into the JSON files and plugins.js for MV/MZ (or back into the NW.js package), into the .rgss* archive or Data files for VX Ace/VX/XP, and into the .ldb/.lmt/.lmu files for 2000/2003. Every line is checked first — if a control code or placeholder is missing from the translation, that line is not written.

  5. Launch the game and check

    Press Launch game and play the first scenes, open the menu and start a battle. Because RPG Maker has no separate translation layer, there is no in-game language switch: the game simply starts in your language. To go back to the original, restore the first backup in Backups and memory.

Fonts, encodings and missing letters

Many RPG Maker games ship their own font in a fonts folder, and that font may not contain the letters of your language — they then appear as empty boxes or disappear. Old 2000/2003 games add a second problem: their code page may not be able to store those letters at all.

Lexi checks both. For 2000/2003 it keeps the original encoding when your translation fits into it, and otherwise saves the text as UTF-8 and records that in RPG_RT.ini. If the game's fonts or encoding are missing letters and your language uses accented Latin letters, the Autopilot card lists the missing letters and suggests Smart Deaccent. It is made for Turkish: ç, ö and ü, which most fonts already have, stay as they are, and only ğ, ş, ı and İ are written as g, s, i and I; tags and codes stay untouched. Lexi does not replace RPG Maker fonts automatically, so if you would rather keep every accent, swapping the game's font for one that contains your letters is a manual job.

Practical tips for a cleaner translation

Names & glossary
Lexi picks up actor names from the database (and speaker names in MZ) and keeps them unchanged, so a hero called Rose does not turn into a flower. Use the Glossary to fix recurring terms — town names, spells, items — so they read the same everywhere.
What stays untranslated
Text drawn into pictures (title screens, signs) is part of the image, not data. Text written inside plugin .js code or custom Ruby scripts is code, so Lexi leaves it alone; in VX Ace/VX/XP only the built-in Vocab messages are taken from the scripts. Plugin commands and script calls are skipped on purpose.
Quality & CSV
The Quality and editing page finds empty, untranslated or broken lines. Retranslate problems sends only those lines again, and you can fix any line in the built-in editor or export/import CSV to review it in Excel or LibreOffice.
Game updates
An update usually replaces the data files with new originals. Scan and translate again: finished lines come back from the translation memory, and only new or changed lines go to the engine.
Backups
Open Backups and memory and press Restore to put the files back as they were on the chosen date; a safety backup of the current state is made first. Your first backup is locked automatically, and you can lock others to keep them.

Personal use and sharing

A translation made this way is for your own use. The game's story, text and art belong to its developer, so before you share a translated patch publicly (for example with Lexi's patch .zip export), ask the developer for permission.

FAQ / RPG Maker translation

Short answers.

Is Lexi Game Translator free?

Yes. The Basic tier is free, needs no account or sign-in, and translates with the keyless built-in Google and Microsoft Edge chain (plus Bing and Yandex if you provide your own API key). AI translation is optional and unlocked with Lexi Pro ($6/month on Patreon), with a one-time 3-day free AI trial per computer.

Which RPG Maker versions work?

RPG Maker MV, MZ, VX Ace, VX, XP and 2000/2003. Lexi detects the version from the game folder. It reads MV/MZ data files and js/plugins.js, games packed with NW.js (package.nw or a ZIP attached to the .exe), and the .rgssad, .rgss2a and .rgss3a archives of XP, VX and VX Ace directly.

Does Lexi change my game files?

Yes. RPG Maker has no separate translation folder, so the translation is written into the game's own data files (or into its archive). Before writing, Lexi copies every file it changes into a backup folder inside the game folder and locks the first backup automatically. Restore in Backups and memory brings the original back.

Can I switch back to the original language?

RPG Maker translations have no in-game language switch. To go back, restore the original backup in Backups and memory. Finished lines stay in Lexi's translation memory, so you do not have to translate them again later.

Letters show as boxes or are missing. What can I do?

Lexi checks the fonts in the game's fonts folder and, for 2000/2003 games, the text encoding. If letters of your language are missing and it uses accented Latin letters, Autopilot suggests Smart Deaccent. It keeps ç, ö and ü and writes only the Turkish letters ğ, ş, ı and İ as g, s, i and I. Lexi does not swap RPG Maker fonts automatically.

Why are some texts still in the original language?

Text drawn into pictures, text written inside plugin or script code, plugin commands and script calls are not translated. Lexi skips code on purpose so the game keeps working.

Can I share my translation with others?

Lexi can export a translation patch as a .zip file, but the game's text belongs to its developer. Translate for your own use, and ask the developer for permission before you share a translated patch publicly.
