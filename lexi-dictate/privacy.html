01 / Privacy Policy / English

Your voice, your key.

LexiDictate turns your speech into text on Windows. To do that, it sends your recording directly from your computer to Google's Gemini API, using the API key you add yourself. Lexi Apps does not run a server that receives your voice or your text.

Last updated / 25 November 2026

What Lexi Apps receives

  • Nothing during normal use. LexiDictate has no user accounts, no analytics, no tracking and no advertising.
  • The only exception is a problem report that you decide to send yourself (see “Problem reports” below). You see the full report before it is sent.
  • Lexi Apps never receives your recordings, your dictated text or your API keys.

What stays on your computer

  • Settings file %APPDATA%\LexiDictate\config.json: your settings, shortcuts, custom vocabulary, excluded apps, your Google AI Studio API keys and your last 15 dictations (the original and the final text). Your API key values are encrypted with Windows DPAPI (tied to your Windows user account on this PC); the rest of the file (settings, vocabulary and your last 15 dictations) is stored as plain JSON so anyone who can open your Windows user account can read those fields.
  • Diagnostic log %APPDATA%\LexiDictate\logs\lexidictate.log (small, replaced as it grows): technical events such as start and stop, durations, character counts, model names, error messages and the names of games that paused dictation in Game Mode. It does not contain the text you dictate.
  • Recordings are kept in memory only. If a dictation fails, its recording is kept in memory for up to 10 minutes so you can retry it; it is never written to disk. Quick Selection Translation keeps its last 20 results in memory only.
  • If you turn on “Start automatically with Windows”, a startup entry is added to your Windows user registry. It is removed when you turn the option off or uninstall the app.
  • Downloaded updates are saved temporarily in %TEMP%\lexidictate_update.

What is sent to Google (Gemini API) and why

  • Your microphone audio, only while you hold or toggle the dictation shortcut, so Google can turn it into text. Depending on your settings it is streamed live, sent as one recording, or both.
  • Text to clean up or translate, together with your custom vocabulary and the instructions for the selected mode (Smart Sentence Polish, Verbatim or Translate to Another Language).
  • Text you select for Quick Selection Translation, only when you click the small translate icon or press its shortcut (up to 1,500 characters).
  • When you test an API key, a request for the list of available models.
  • All of this goes directly from your computer to Google's Gemini API (Google AI Studio), using your own API key. Google's own privacy policy and Gemini API terms decide how Google handles this data, and they can differ between free and paid use. Please read them before you use the app.

Updates

  • If “Automatically check for updates on launch” is on (the default), LexiDictate asks GitHub's public API for the latest LexiDictate release a few seconds after it starts.
  • Update files are downloaded only from LexiDictate's own GitHub releases page and are checked (SHA-256) before they are installed.
  • Like any web request, GitHub sees your IP address and a short app name in the request. You can turn automatic checks off in the settings.

Problem reports

  • A report is sent only when you open “Report an Issue” and press Send.
  • It contains your description, an optional reply email, the app, Windows, Python and Qt versions, a summary of your settings (modes, selected models, shortcuts and the number of API keys, not the keys themselves) and, if you leave that option on, the last lines of the diagnostic log.
  • Before sending, API keys and similar secrets, your Windows user name and user folder paths, other email addresses, IP addresses, your key labels and the names of your excluded apps are masked. The preview shows exactly what will be sent.
  • Reports go to the Lexi Apps report service (running on Cloudflare), which stores them as issues in a private GitHub repository for the developer. Your reply email is used only to answer your report.

Third-party services

  • Google (Gemini API / Google AI Studio): speech recognition, text clean-up and translation, with your own API key.
  • GitHub: update checks and downloads; storage of problem reports.
  • Cloudflare: runs the Lexi Apps report service.
  • Each of these companies has its own privacy policy. Links to the website, Discord, Patreon or Buy Me a Coffee only open in your browser; the app sends them no data.

Children

  • LexiDictate is a general-purpose tool and is not directed at children. Lexi Apps does not knowingly collect personal data from children; the only personal data we can receive is what is in a problem report you choose to send.

Your choices and deleting your data

  • Use “Clear History” in the settings to delete saved dictations, and delete API keys from the key list at any time. You can also revoke a key in Google AI Studio.
  • You can turn off automatic update checks, and you can send a report without the log.
  • Uninstalling removes the program but keeps your settings. To remove all local data, also delete the folder %APPDATA%\LexiDictate (and %APPDATA%\MicDictate, if you used the app under its earlier name).
  • For questions about a report you sent, email us.

Changes to this policy

  • If the app's data handling changes, we will update this page and the “Last updated” date above.

02 / Gizlilik Politikası / Türkçe

Sesiniz, anahtarınız.

LexiDictate, Windows'ta konuşmanızı yazıya çevirir. Bunun için kaydınızı, sizin eklediğiniz API anahtarıyla doğrudan bilgisayarınızdan Google'ın Gemini API'sine gönderir. Lexi Apps'in sesinizi ya da metninizi alan bir sunucusu yoktur.

Son güncelleme / 25 Kasım 2026

Lexi Apps'e ne ulaşır

  • Normal kullanımda hiçbir şey. LexiDictate'te kullanıcı hesabı, analitik, izleme ve reklam yoktur.
  • Tek istisna, kendiniz göndermeye karar verdiğiniz sorun raporudur (aşağıdaki “Sorun raporları” bölümüne bakın). Raporun tamamını göndermeden önce görürsünüz.
  • Ses kayıtlarınız, yazdırdığınız metinler ve API anahtarlarınız Lexi Apps'e hiçbir zaman ulaşmaz.

Bilgisayarınızda kalanlar

  • Ayar dosyası %APPDATA%\LexiDictate\config.json: ayarlarınız, kısayollarınız, özel sözlüğünüz, hariç tuttuğunuz uygulamalar, Google AI Studio API anahtarlarınız ve son 15 dikteniz (ilk ve son hâliyle metin). API anahtarı değerleriniz Windows DPAPI ile şifrelenir (bu bilgisayardaki Windows kullanıcı hesabınıza bağlıdır); dosyanın geri kalanı (ayarlarınız, sözlüğünüz ve son 15 dikteniz) düz JSON olarak saklanır ve Windows hesabınıza erişebilen kişilerce okunabilir.
  • Tanılama günlüğü %APPDATA%\LexiDictate\logs\lexidictate.log (küçük; büyüdükçe eskisi silinir): başlama ve bitiş, süreler, karakter sayıları, model adları, hata iletileri ve Oyun Modu'nda dikteyi duraklatan oyunların adları gibi teknik kayıtlar. Yazdırdığınız metin bu günlükte yer almaz.
  • Ses kayıtları yalnız bellekte tutulur. Bir dikte başarısız olursa, yeniden deneyebilmeniz için kaydı en çok 10 dakika bellekte kalır; diske hiç yazılmaz. Hızlı Seçim Çevirisi de son 20 sonucunu yalnız bellekte tutar.
  • “Windows açılışında otomatik başlat” seçeneğini açarsanız Windows kullanıcı kayıt defterinize bir başlangıç kaydı eklenir. Seçeneği kapattığınızda ya da uygulamayı kaldırdığınızda bu kayıt silinir.
  • İndirilen güncellemeler geçici olarak %TEMP%\lexidictate_update klasörüne kaydedilir.

Google'a (Gemini API) ne gönderilir, neden

  • Mikrofon sesiniz; yalnız dikte kısayolunu basılı tuttuğunuz ya da açtığınız sürece, Google onu yazıya çevirebilsin diye. Ayarlarınıza göre canlı akış olarak, tek bir kayıt olarak ya da ikisi birden gönderilir.
  • Düzeltilecek ya da çevrilecek metin; özel sözlüğünüz ve seçili kipin (Akıllı Cümle Düzeltme, Birebir ya da Başka Dile Çevir) talimatlarıyla birlikte.
  • Hızlı Seçim Çevirisi için seçtiğiniz metin; yalnız küçük çeviri simgesine tıkladığınızda ya da kısayoluna bastığınızda (en çok 1.500 karakter).
  • Bir API anahtarını sınadığınızda, kullanılabilir modellerin listesi için bir istek.
  • Bunların hepsi sizin API anahtarınızla, doğrudan bilgisayarınızdan Google'ın Gemini API'sine (Google AI Studio) gider. Google'ın bu verileri nasıl işlediğini Google'ın kendi gizlilik politikası ve Gemini API koşulları belirler; bu koşullar ücretsiz ve ücretli kullanımda farklı olabilir. Uygulamayı kullanmadan önce lütfen bunları okuyun.

Güncellemeler

  • “Başlangıçta güncellemeleri otomatik denetle” açıksa (varsayılan), LexiDictate açıldıktan birkaç saniye sonra GitHub'ın herkese açık API'sine en son LexiDictate sürümünü sorar.
  • Güncelleme dosyaları yalnız LexiDictate'in kendi GitHub sürüm sayfasından indirilir ve kurulmadan önce doğrulanır (SHA-256).
  • Her web isteğinde olduğu gibi GitHub, IP adresinizi ve istekteki kısa uygulama adını görür. Otomatik denetimi ayarlardan kapatabilirsiniz.

Sorun raporları

  • Rapor yalnız “Sorun Bildir” penceresini açıp Gönder'e bastığınızda gönderilir.
  • Raporda açıklamanız, isteğe bağlı yanıt e-postanız, uygulama, Windows, Python ve Qt sürümleri, ayarlarınızın özeti (kipler, seçili modeller, kısayollar ve API anahtarlarının sayısı; anahtarların kendisi değil) ve bu seçeneği açık bırakırsanız tanılama günlüğünün son satırları bulunur.
  • Göndermeden önce API anahtarları ve benzeri gizli bilgiler, Windows kullanıcı adınız ve kullanıcı klasörü yollarınız, başka e-posta adresleri, IP adresleri, anahtar etiketleriniz ve hariç tuttuğunuz uygulamaların adları maskelenir. Önizleme, gönderilecek metnin aynısını gösterir.
  • Raporlar Lexi Apps rapor hizmetine (Cloudflare üzerinde çalışır) gider ve geliştirici için gizli bir GitHub deposunda kayıt (issue) olarak saklanır. Yanıt e-postanız yalnız raporunuza cevap vermek için kullanılır.

Üçüncü taraf hizmetler

  • Google (Gemini API / Google AI Studio): sizin API anahtarınızla konuşma tanıma, metin düzeltme ve çeviri.
  • GitHub: güncelleme denetimi ve indirme; sorun raporlarının saklanması.
  • Cloudflare: Lexi Apps rapor hizmetini çalıştırır.
  • Bu şirketlerin her birinin kendi gizlilik politikası vardır. Web sitesi, Discord, Patreon ya da Buy Me a Coffee bağlantıları yalnız tarayıcınızda açılır; uygulama bunlara veri göndermez.

Çocuklar

  • LexiDictate genel amaçlı bir araçtır ve çocuklara yönelik değildir. Lexi Apps çocuklardan bilerek kişisel veri toplamaz; bize ulaşabilecek tek kişisel veri, göndermeyi seçtiğiniz bir sorun raporunda yer alanlardır.

Seçenekleriniz ve verilerinizi silme

  • Kayıtlı dikteleri silmek için ayarlardaki “Geçmişi Temizle” düğmesini kullanın; API anahtarlarını anahtar listesinden istediğiniz zaman silebilirsiniz. Bir anahtarı Google AI Studio'dan da iptal edebilirsiniz.
  • Otomatik güncelleme denetimini kapatabilir, raporu günlük eklemeden gönderebilirsiniz.
  • Uygulamayı kaldırmak programı siler ama ayarlarınızı bırakır. Bilgisayarınızdaki tüm verileri silmek için %APPDATA%\LexiDictate klasörünü de silin (uygulamayı eski adı MicDictate ile kullandıysanız %APPDATA%\MicDictate klasörünü de).
  • Gönderdiğiniz bir raporla ilgili sorularınız için bize e-posta yazın.

Bu politikadaki değişiklikler

  • Uygulamanın verileri işleme biçimi değişirse bu sayfayı ve yukarıdaki “Son güncelleme” tarihini güncelleriz.
