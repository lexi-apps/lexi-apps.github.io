Lexi Game Translator / 18 engines / Compatibility

Does Lexi work with my game?

Lexi Game Translator supports 18 game engines. Below, each one is listed with the files that identify it in a game folder, what Lexi translates and the limits you should know about — so you can check your game before you download anything.

Detected automatically

Drop the game folder: Lexi recognises the engine from its files and runs a read-only scan first. Nothing changes until you press Translate.

Backed up first

Before Lexi writes into game files, it copies what it changes into a backup folder inside the game folder and locks your first backup.

Codes stay intact

Every engine has its own list of control codes, tags and variables. A translated line in which one of them went missing is not written.

  1. 01

    Ren'Py

    Step-by-step guide →
    How to recognise it
    A game/ folder with .rpy, .rpyc or .rpa files, usually next to a renpy/ folder.
    What Lexi translates
    Dialogue, choices and interface text, also from compiled .rpyc scripts inside .rpa archives. Written as a separate translation into game/tl/<language>/ with an in-game language switch.
    Limits
    The game's own scripts are not edited. In free Basic the in-game language menu shows a small “Translated with Lexi” line.
  2. 02

    RPG Maker MZ

    Step-by-step guide →
    How to recognise it
    data/System.json together with js/rmmz_core.js — or the same files packed into package.nw or into the .exe.
    What Lexi translates
    Dialogue, choices, speaker names, database names and descriptions, menu terms and text-like plugin parameters — written into the JSON files and js/plugins.js after a backup.
    Limits
    Text inside plugin .js code, plugin commands and script calls is skipped on purpose. No in-game language switch.

    Step-by-step guide →
    How to recognise it
    www/data/System.json (or data/ with js/rpg_core.js) — or packed into package.nw or the .exe.
    What Lexi translates
    Dialogue, choices, database names and descriptions, menu terms and text-like plugin parameters — written into the JSON files and js/plugins.js after a backup. Control codes like \C[1] stay intact.
    Limits
    Text inside plugin .js code, plugin commands and script calls is skipped on purpose. No in-game language switch.

    Step-by-step guide →

    What Lexi translates
    Dialogue, choices, database names and descriptions and the built-in Vocab messages — read from and written back into the archive or the Data files.
    Limits
    Text inside custom Ruby scripts is code and is not translated (only Vocab). No in-game language switch.

    Step-by-step guide →
    How to recognise it

    What Lexi translates
    Dialogue, choices, database names and descriptions and the built-in Vocab messages — inside the archive or the Data files.
    Limits
    Text inside custom Ruby scripts is not translated. No in-game language switch.

    RPG Maker XP

    Step-by-step guide →
    How to recognise it
    A .rgssad archive, or .rxdata files in Data/.
    What Lexi translates
    Dialogue, choices, database names and descriptions — inside the archive or the Data files.
    Limits
    Text inside custom Ruby scripts is not translated. No in-game language switch.
  7. 07

    RPG Maker 2000 / 2003

    Step-by-step guide →
    How to recognise it
    RPG_RT.ldb together with RPG_RT.lmt, RPG_RT.exe, RPG_RT.ini or Map*.lmu maps.
    What Lexi translates
    Dialogue, choices and database terms in the .ldb, .lmt and .lmu files.
    Limits
    Old code pages (Shift-JIS, Windows-1252) cannot hold every letter: Lexi keeps the original encoding when the text fits, otherwise saves UTF-8 and records it in RPG_RT.ini; Autopilot can suggest Smart Deaccent.
  8. 08

    Unity (Mono)

    Step-by-step guide →
    How to recognise it
    A <Game>_Data folder with Managed/Assembly-CSharp.dll.
    What Lexi translates
    Readable language files (.po, .csv, .json) directly. Otherwise, with your approval, Autopilot installs BepInEx and XUnity.AutoTranslator, pre-extracts packed text from .assets and Assembly-CSharp.dll read-only, and Live Bridge translates new lines while you play.
    Limits
    Setup is blocked for games with anti-cheat. TextMeshPro games need a font asset with your letters; Lexi does not download fonts for Unity.
  9. 09

    Unity (IL2CPP)

    Step-by-step guide →
    How to recognise it
    GameAssembly.dll next to the .exe, or an il2cpp_data folder inside <Game>_Data.
    What Lexi translates
    Same as Mono: language files directly, or Autopilot with BepInEx and XUnity.AutoTranslator; packed text is pre-extracted read-only from .assets and global-metadata.dat, plus Live Bridge.
    Limits
    Setup is blocked for games with anti-cheat. The game's .assets, .dll and metadata files are only read, never written.
  10. 10

    Unreal Engine 4 / 5

    Step-by-step guide →
    How to recognise it
    A Content/Paks folder with .pak files, a Content/Localization folder, or Engine/Binaries.
    What Lexi translates
    Open .locres/.po tables (loose or in an unencrypted .pak), written into a separate ~mods/ patch. Closed games: Autopilot installs UE4SS, collects text while the game runs and swaps it in on screen. Optional font patch.
    Limits
    Anti-cheat (EasyAntiCheat, BattlEye) blocks the UE4SS route. AES-encrypted or Oodle-compressed data cannot be read directly. UE4SS needs a 64-bit *-Win64-Shipping.exe.
  11. 11

    Godot 3 / 4

    How to recognise it
    A project.godot file, a .pck file, or a game .exe with the .pck embedded.
    What Lexi translates
    .po and localization .csv files, text in .tscn/.tres scenes, JSON, Dialogic timelines and Dialogue Manager .dialogue files — loose or inside the .pck, which is patched after a backup.
    Limits
    Encrypted .pck entries are skipped. With per-language .po files, Lexi adds your language and leaves the others untouched.
  12. 12

    TyranoScript / TyranoBuilder

    How to recognise it
    A tyrano/ folder (also under resources/app/), a resources/app.asar containing Tyrano, or data/scenario/ next to an index.html that loads Tyrano.
    What Lexi translates
    Scenario .ks scripts: dialogue, choice buttons and text in tags such as [glink] or [ptext] — loose or inside the Electron app.asar.
    Limits
    Tyrano tags stay as they are; a line in which a tag went missing is not written.
  13. 13

    WOLF RPG Editor

    Step-by-step guide →
    How to recognise it
    A Data.wolf (or other .wolf) archive, or Data/BasicData and Data/MapData folders.
    What Lexi translates
    Messages and choices from map and common events, text from string operations and event calls, and database text fields — in the Data folder or inside the .wolf archive.
    Limits
    Password-protected .wolf archives and WOLF RPG Editor Pro files are skipped. Editor 2 games use Shift-JIS; Autopilot can suggest Smart Deaccent.
  14. 14

    KiriKiri (KAG)

    How to recognise it
    .xp3 archives, startup.tjs, a krkr*.exe, or data/system/Config.tjs with .ks scripts.
    What Lexi translates
    KAG .ks scenario scripts — dialogue, speaker names and [link] choices — loose or inside readable .xp3 archives, respecting patch.xp3 layers.
    Limits
    Encrypted .xp3 entries cannot be read. The original encoding is kept; a Shift-JIS script that cannot hold your letters is saved as UTF-16.
  15. 15

    QSP

    How to recognise it
    A .qsp, .gam or .qsps game file.
    What Lexi translates
    Text printed by commands such as *pl, pl or msg, plain printed strings and action names, written back into the game file.
    Limits
    Location names, image paths, jumps, conditions and variables are never changed. An old Windows-1251 file that cannot hold your letters is saved in the newer UTF-16 QSP format.
  16. 16

    HTML / Twine

    How to recognise it
    A Twine story .html file (Twine 2 story data or a Twine 1 store area), in the game folder, www/ or resources/app/.
    What Lexi translates
    Passages, links and macro text of SugarCube and Harlowe stories, plus SugarCube's built-in interface strings — written into the .html file.
    Limits
    Macros, links and code keep working; a line in which a macro or link went missing is not written.
  17. 17

    GameMaker

    How to recognise it
    A data.win (or game.unx, game.ios, game.droid), or a single-file GameMaker: Studio 1.4 .exe.
    What Lexi translates
    Natural-language strings in the game's string table (asset and symbol names excluded) and external JSON, CSV, TXT or INI language files — patched after a backup.
    Limits
    Fonts are built into the game; Lexi checks them for your letters and Autopilot can suggest Smart Deaccent when letters are missing.
  18. 18

    SRPG Studio

    How to recognise it
    A data.dts archive, a .srpgs project file, runtime.rts, or project.dat with folders such as Localization or Script.
    What Lexi translates
    Localization/ files, interface text in Plugin/Script .js files, text in Material, and the story and database in project.dat when it can be read — loose or inside data.dts.
    Limits
    If project.dat uses a custom encryption and there is no Localization folder, only the interface text from scripts can be translated — Lexi tells you so.

No engine matches. Try a file name from your game folder, such as .exe, .pak or data.

Good to know for every engine

  • Pictures are not text. The scan collects text the game stores as text. Words drawn into images — title screens, signs, buttons painted into the artwork — are pixels and are not part of it.
  • No protection is broken. Lexi reads what a game stores openly or with the engine's standard key. Encrypted or password-protected data is skipped, and Lexi tells you why when it finds nothing to translate.
  • Single-player only. For Unity and Unreal, plugin setup is blocked when anti-cheat (EasyAntiCheat or BattlEye) is found in the game folder.
  • Missing letters. Where a game's fonts or text encoding cannot show your letters, Autopilot says so: Unreal games can get a font patch, Ren'Py games get a bundled fallback font, and several other engines get a Smart Deaccent suggestion.
  • Your translation, your use. A game's text belongs to its developer. Translate for your own use, and ask the developer before you share a translated patch publicly.

FAQ / Compatibility

Short answers.

How do I know if Lexi works with my game?

Drop the game folder onto Lexi. It recognises the engine from the game's files, shows it on the overview screen and runs a read-only scan that counts the lines it can translate. Nothing in the game is changed until you press Translate.

What if my game's engine is not on the list?

If Lexi does not recognise one of the 18 supported engines in the folder, it shows the game as not supported and does not write a translation into it.

Does Lexi work with encrypted games?

Lexi reads what a game stores openly or with the engine's standard key. Encrypted or password-protected data, such as AES-encrypted Unreal .pak files, encrypted KiriKiri .xp3 entries, password-protected WOLF RPG archives or encrypted Godot .pck entries, cannot be read directly. Lexi does not try to break such protection; for Unreal games it can use the UE4SS route instead.
